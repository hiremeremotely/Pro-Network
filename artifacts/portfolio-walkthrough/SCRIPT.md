# Portfolio Creation Walkthrough — Director's Treatment

- **Promise:** A portfolio can start from permitted work links or from details entered by hand; either way, the creator reviews it before saving.
- **Identity:** ProConnect's restrained purple-and-white interface palette, DM Sans for interface copy, Space Grotesk for large type. Use the wordmark as plain text, not an invented logo.
- **Hero:** A portfolio project card that changes from a source link into a reviewed, saved work sample.
- **Motion:** Link lines draw into a discovery panel; cards unfold from reviewed metadata; a form assembles field by field.
- **Arc:** Start with the choice, move quickly through link discovery, slow down for manual review, and end on the privacy state.
- **Payoff:** The two paths converge into one portfolio list, while a private label remains on the source link.
- **Format and runtime:** 16:9 landscape, 40 seconds.
- **Sound:** One light, modern instrumental bed; no voiceover or sound effects. The music should support the quick link sequence and leave the privacy message readable. No beat synchronization is claimed before checking the generated bed.

## Full shot script

### Shot 01 / 00.00–06.00s / 6.00s — “YOUR WORK, TOGETHER.”

**Purpose:** Establish that the viewer can choose a route, rather than suggesting the service automatically imports or publishes everything.

**Exact content and timing:**
- 00.00s: “PROCONNECT / PORTFOLIO”
- 00.20s: “YOUR WORK,”
- 00.65s: “TOGETHER.”
- 01.55s: “Start from links or add a project yourself.”
- 02.30s: compact interface label “PROFILE  /  PORTFOLIO”
- 03.00s: panel option “Build from links”

- 04.55s: caption “Review before saving.”
- All text remains readable until the transition starts at 05.15s.

**Composition:** Open on deep ink-indigo with a violet link-shaped outline centered and nearly frame-height. Oversized white type takes the left half; the right third contains a floating cropped portfolio panel with the two real mode labels. Accent violet and pale lavender match ProConnect's visible interface family. No fabricated ProConnect symbol.

**Artistic idea:** The outline is a link-shaped aperture: it opens like two connected loops, revealing the workspace as if the viewer were looking through a source URL.

**Timed choreography:** 00.00–00.45s the loop mark snaps from two small joined rings to a tall hero outline; a thin secondary rule appears by 00.20s. 00.45–01.35s the two headline lines unmask on separate beats. 01.35–02.25s the interface panel turns slightly toward camera and sharpens. 02.25–03.85s the mode labels light up one at a time. 03.85–04.75s a violet connector line traces between the two options. 04.75–05.15s the reminder appears. From 05.15s to 06.00s the line scales through camera into a full-frame outline while the panel folds away; no empty field.

**Transition contract:** The violet connector-line end becomes the caret-side of the next shot's URL input; match its position and hue across the cut while the camera settles from the push.

**Assets and technique:** CSS/SVG drawn interface surfaces, no raster assets. Use mask reveals, a drawn SVG path, a controlled 3D panel turn, and a camera push; keep all UI artwork noninteractive.

**Sound intent:** Music begins with a light percussive pulse. No sound effect or spoken instruction.

**Assets and technique:** HTML card geometry, SVG rule and link outline, privacy lock glyph, split color-field transition, one pullback. No fabricated logo mark; display “ProConnect” as text.

**Sound intent:** Resolve the instrumental bed under the final line. The music may loop with the visual mark, but do not claim a seamless musical loop unless verified.

## Pre-code review

- The four shots alternate dark typographic opener, close bright import panel, centered warm form, and wide cream-to-indigo overview; adjacent shots change framing and visual structure.
- Link import is shown as a suggestion/review/save process, not an automatic or unrestricted scrape. Personal-site sample pages and GitHub are illustrative.
- Manual entry includes the real editable fields and does not imply external source scraping.
- All new portfolio items start private; external source URLs are not represented as publicly visible by default.
- Every shot contains an action after its opening reveal. Handoffs begin before the final 15–20% and carry a visible violet line, checkmark, page corner, or link outline across cuts.
- UI copy is set larger than a typical dense form so it remains readable at 16:9 preview size. Tiny decorative text is omitted.
